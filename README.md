# CrossDesk 사용 설명서

> macOS와 Windows를 같은 네트워크에서 곧바로 이어, **한쪽 화면을 다른 쪽에서 보고 조작하고 파일을 주고받는** 데스크톱 앱입니다.

계정도 중계 서버도 없습니다. 두 컴퓨터 사이에 TCP 연결 하나만 열립니다. 그래서 인터넷을 거치지 않고, 대신 **두 컴퓨터가 같은 공유기(같은 네트워크)에 있어야** 합니다.

- 지원: macOS 12.3 이상(Apple Silicon·Intel), Windows 10/11 64비트
- 앱 화면의 버튼 이름은 영어입니다. 이 문서에서는 `Share this computer`처럼 그대로 인용합니다.
- 소개 자료: [brochure.html](docs/brochure.html)

---

## 1. 설치

| | |
| --- | --- |
| **macOS** | 디스크 이미지(`CrossDesk-<버전>.dmg`)를 열고 CrossDesk를 **응용 프로그램** 폴더로 끌어 넣습니다. |
| **Windows** | 설치 프로그램(`CrossDesk-Setup-<버전>.exe`)을 실행합니다. 관리자 권한은 필요 없습니다. |

> macOS에서 "확인되지 않은 개발자" 경고가 뜨면, 앱을 **오른쪽 클릭 → 열기**를 한 번만 해 주면 그 뒤로는 그냥 열립니다.

### 처음 실행할 때 해 둘 것

**macOS — 내 화면을 공유하려는 경우** 시스템 설정 → 개인정보 보호 및 보안에서 두 가지를 허용합니다.

| 권한 | 없으면 생기는 일 |
| --- | --- |
| **화면 기록** | 상대에게 검은 화면만 보입니다 |
| **손쉬운 사용** | 상대가 조작해도 반응하지 않습니다 |

허용한 뒤에는 **앱을 완전히 종료했다가 다시 실행해야** 적용됩니다.

**Windows** 앱 자체 권한은 없습니다. 처음 실행할 때 뜨는 **방화벽 허용** 창에서 접속을 허용하면 됩니다. 나중에 수동으로 열려면 `47820` 포트의 TCP 인바운드를 사설 네트워크에 허용합니다.

## 2. 화면 구성

창 위쪽에 탭 두 개가 있습니다. 역할을 오갈 때 탭만 바꾸면 되고, **탭을 바꿔도 진행 중인 연결은 끊기지 않습니다.**

| 탭 | 하는 일 |
| --- | --- |
| `Share this computer` | 내 화면을 상대에게 보여 줍니다 (호스트) |
| `Connect to remote` | 상대 화면을 보고 조작합니다 (뷰어) |

오른쪽 위의 색 점이 현재 상태입니다. **Connected**(연결됨), **Connecting…**(연결 중), **Waiting for a viewer to connect**(대기 중), **Disconnected**(끊김).

---

## 3. 처음 연결하기

### 내 화면을 보여 주려면 (호스트)

1. `Share this computer` 탭에서 **`Start sharing`** 을 누릅니다.
2. 왼쪽에 접속 정보가 나타납니다. 이 세 가지를 상대에게 알려 주세요.
   - **Addresses** — 이 컴퓨터의 주소 (예: `192.168.0.10 : 47820`). 여러 개면 상대와 같은 대역인 것을 고릅니다.
   - **Port** — `47820`
   - **Code** — 여섯 자리 숫자
3. 상대가 접속하면 상태가 **Connected** 로 바뀝니다.
4. 공유를 끝내려면 **`Stop sharing`** 을 누릅니다.

### 상대 화면에 접속하려면 (뷰어)

1. `Connect to remote` 탭으로 갑니다.
2. 상대가 알려 준 **Host**(주소), **Port**, **Code** 를 넣고 **`Connect`** 를 누릅니다.
3. 잠시 뒤 상대 화면이 나타납니다. 끊으려면 **`Disconnect`** 를 누릅니다.

> 코드는 화면에 뜬 뒤 **약 8초 안에** 입력해야 합니다. 늦었다면 다시 시도하면 됩니다. 호스트 화면의 코드는 그대로 유효합니다.

---

## 4. 두 번째부터는 코드 없이

코드로 한 번 접속하면 호스트가 그 기기에 **인증 키를 발급**하고, 뷰어가 자동으로 보관합니다. 그 뒤로는 코드를 주고받을 필요가 없습니다.

**뷰어 쪽 — Quick connect**
연결 입력줄 아래에 저장된 호스트 목록이 생깁니다. **`Connect`** 를 누르면 코드 없이 바로 이어집니다. 목록에서 지우려면 **`✕`** 를 누릅니다.

**호스트 쪽 — Issued keys**
어떤 기기에 키를 내줬는지 목록으로 보여 줍니다. 기기 이름, 발급 시점, 마지막 사용 시점이 함께 표시됩니다.

- **`Revoke`** — 그 기기의 키만 회수합니다.
- **`Revoke all`** — 전부 회수합니다.
- 회수된 기기가 접속을 시도하면 거부되고, 뷰어 쪽 저장분도 자동으로 지워집니다. 다시 쓰려면 코드로 새로 인증하면 됩니다.

> 쓰지 않는 기기는 회수해 두는 편이 안전합니다. 키를 가진 기기는 언제든 코드 없이 들어올 수 있습니다.

## 5. 원격으로 조작하기

**양쪽 모두 켜야 동작합니다.** 하나라도 꺼져 있으면 입력이 전달되지 않습니다.

| 어디 | 무엇 | 기본값 |
| --- | --- | --- |
| 호스트 | `Allow remote control` | 켜짐 |
| 뷰어 | `Remote control` | 꺼짐 |

뷰어에서 켜면 화면 영역 안의 마우스 이동·클릭·스크롤과 키보드 입력이 호스트로 건너갑니다. 조작을 즉시 막아야 할 때는 **호스트에서 `Allow remote control` 을 끄면** 그 순간부터 입력이 무시됩니다(연결은 유지).

알아 둘 점

- 조작은 호스트의 **주 화면** 기준으로 맞춰집니다. 모니터가 여러 대여도 주 화면만 대상입니다.
- **Windows**: 관리자 권한으로 실행된 창과 UAC 동의 창은 기본적으로 조작되지 않습니다 → [8번 항목](#8-windows-관리자-권한-화면까지-조작하기) 참고.
- **macOS**: 조작이 전혀 안 되면 손쉬운 사용 권한을 확인하세요.

---

## 6. 파일 주고받기

양쪽 모두 **`Send file…`** 버튼으로 보낼 수 있습니다. 여러 개를 한 번에 고를 수 있고, 진행률이 목록으로 표시됩니다.

받은 파일은 자동으로 저장됩니다.

- 저장 위치: **다운로드 폴더 아래 `CrossDesk` 폴더**
- 같은 이름이 있으면 `파일 (1).확장자` 처럼 번호를 붙여 기존 파일을 덮어쓰지 않습니다.
- 한 개당 최대 4 GiB

> 받는 쪽 확인 없이 자동으로 저장됩니다. 신뢰하는 상대와만 쓰고, 받은 파일은 열기 전에 확인하세요.

## 7. 창을 닫아도 꺼지지 않습니다

CrossDesk는 메뉴 막대(macOS)와 알림 영역(Windows)에 **트레이 아이콘**을 둡니다.

- **창의 X 버튼은 창만 숨깁니다.** 공유 중이었다면 계속 공유됩니다.
- 트레이 아이콘을 누르거나 메뉴에서 **`Open CrossDesk`** 를 고르면 창이 다시 열립니다.
- **완전히 종료하려면 트레이 메뉴의 `Quit CrossDesk`** 를 누릅니다.

### Windows 시작 시 자동으로 공유하기

호스트 화면의 **`Start hosting when Windows starts`** 를 켜면, 윈도우에 로그인할 때 CrossDesk가 **창 없이 트레이에만 떠서 곧바로 공유를 시작**합니다. 인증 키를 받아 둔 기기라면 코드 없이 접속할 수 있으므로, 사람이 없는 컴퓨터에 접속할 때 유용합니다.

끄면 등록이 지워지고, 설치 프로그램으로 앱을 제거할 때도 함께 정리됩니다.

## 8. Windows 관리자 권한 화면까지 조작하기

원격으로 무언가를 "관리자 권한으로 실행"하면 제어가 멈추는 것을 보게 됩니다. 이는 고장이 아니라 Windows의 보안 정책입니다. 관리자 권한 창과 UAC 동의 창은 일반 프로그램의 입력을 받지 않습니다. **CrossDesk를 관리자 권한으로 실행해도 마찬가지입니다.**

이걸 넘어서려면 호스트 화면의 **`Elevated control`** 에서 **`Enable…`** 을 누릅니다.

1. 관리자 승인(UAC) 창이 **한 번** 뜹니다. 승인하면 배경 서비스가 등록됩니다.
2. 표시가 `● off` → `● starting…` → `● active` 로 바뀌면 준비된 것입니다.
3. 이제 관리자 권한 창은 물론 **UAC 동의 창까지 뷰어 화면에 보이고, 원격에서 누를 수 있습니다.**
4. 재부팅해도 유지됩니다. 끄려면 **`Disable`** 을 누릅니다(승인 한 번 더).

> ⚠️ **켜기 전에 생각해 볼 것.** 이 기능을 켜면 원격 제어를 허용한 상대가 UAC 동의 창을 스스로 승인할 수 있습니다. 곧 **관리자 권한을 맡기는 것**과 같습니다. 필요한 동안만 켜고, 끝나면 `Disable` 로 되돌리기를 권합니다.

## 9. 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 접속 자체가 안 됨 | 두 컴퓨터가 **같은 네트워크**인지, 주소·포트를 정확히 넣었는지. Windows 호스트면 방화벽에서 `47820` 이 열려 있는지 |
| 인증 실패 | 호스트 화면의 현재 코드를 다시 확인. 코드 입력은 약 8초 안에 |
| 저장된 호스트로 접속이 거부됨 | 호스트가 키를 회수한 경우입니다. 코드로 다시 인증하면 새 키가 발급됩니다 |
| 검은 화면만 보임 | (macOS 호스트) 화면 기록 권한을 허용하고 **앱 재시작** |
| 조작해도 반응이 없음 | 양쪽 체크박스가 모두 켜져 있는지. (macOS 호스트) 손쉬운 사용 권한 |
| 관리자 창·UAC 창에서만 안 됨 | 정상입니다. 필요하면 `Elevated control` 을 켜세요 ([8번](#8-windows-관리자-권한-화면까지-조작하기)) |
| 화면이 계속 "Waiting for the remote screen…" | 연결은 됐지만 첫 프레임이 아직 오지 않은 상태입니다. 호스트의 화면 캡처 권한을 확인하세요 |
| "No network address found" | 그 컴퓨터에 유효한 네트워크 주소가 없습니다. Wi-Fi·유선 연결을 확인하세요 |
| X를 눌렀는데 안 꺼짐 | 의도된 동작입니다. 트레이 메뉴의 `Quit CrossDesk` 로 종료하세요 |

## 10. 안전하게 쓰기

CrossDesk는 **신뢰하는 네트워크와 신뢰하는 상대**를 전제로 만들어졌습니다.

- **통신은 암호화되지 않습니다.** 같은 네트워크의 다른 사람이 마음먹으면 화면과 입력 내용을 볼 수 있습니다. 공용 Wi-Fi처럼 믿을 수 없는 망에서는 쓰지 말고, 꼭 필요하면 VPN이나 SSH 터널 안에서 쓰세요.
- **코드는 신뢰하는 사람에게만** 알려 주세요. 코드를 아는 사람은 접속할 수 있고, 추측 시도 횟수에 제한이 없습니다.
- 원격 제어가 필요 없는 동안에는 호스트의 `Allow remote control` 을 꺼 두세요.
- 화면에 비밀번호나 민감한 문서를 띄운 채로 세션을 유지하지 마세요.
- 세션이 끝나면 `Stop sharing` 으로 정리하고, 임시로 열어 둔 방화벽 규칙이 있다면 되돌리세요.
- 다운로드 폴더의 `CrossDesk` 폴더를 가끔 확인하세요. 파일은 자동으로 저장됩니다.
